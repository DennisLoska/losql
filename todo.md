# SQL Editor

- SQL editor
- Vim key bindings `useVim`
- api integration + postgres connection
- LSP integration

# SQL Analyzer

- Pipe SQL query
- Display query plan
- Pretty json formatter
- LLM integration to evaluate it instantly
- Hot reload + Vim key bindings
- Toggable

# Result table

- Display query results
- Navigatable using vim key bindings
- Detailed popup view -> inline edits generate update queries 

# Help menu

- shift + ? opens help menu
- lists all available keyboard shortcuts

# Make it vim
- `:q` anywhere exits Losql
- `<ESC>` or `jk` go back to normal mode
- `/` to enable search over the entire TUI
- `<CTRL-h,j,k,l>` to move between windows
