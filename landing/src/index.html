03 / The DNA

Familiar ideas.
A focused SQL home.

Neovim + OpenCode + Harlequin & LazySQL. Built around the way terminal people already work.

01 / Neovim DNA

Modal SQL Editing

Motions, operators d c y > <, registers, dot repeat, undo/redo and / regex search. Use is for the inner SQL Statement or as for the Statement with its delimiter. Keep multiple Buffers open and switch with gt/gT.

Move between Panes with shift+h/j/k/l. Run the Statement under the cursor with Enter. The editing model stays in your hands.

cisgtshift+l
02 / OpenCode DNA

Agent on board.
No API keys.

losql drives the coding CLI already on your PATH: claude, codex, opencode or antigravity. Each Turn starts in an empty temporary directory with the Provider's tools disabled or restricted to read-only mode. Database credentials are stripped from its child environment.

The Agent can request read-only describe and query Steps, then present a Proposal. You decide what enters the Buffer and what runs. Provider restrictions can still allow local file reads; the Schema snapshot, Conversation and requested rows are sent to the chosen Provider. Use agent.dataAccess: "schema" to prevent row queries.

A write Proposal asks for confirmation before a Run. Statements you Run yourself from the Editor execute without that extra prompt.

03 / Harlequin & LazySQL DNA

Terminal Database Craft

In-process SQLite via bun:sqlite and a Postgres Driver connect one Session to your chosen Connection. Browse the Schema snapshot tree, expand namespaces and peek at a Relation with Enter.

Three instant Result views — Table, JSON and Record — make inspection part of the same flow. One compiled binary; Linux and macOS, tested on Linux.

06 / Quick Start

One binary.
Your next Connection.

Build with Bun. Start with the bundled demo, a SQLite file, or a Postgres URL.

01 / Build & install

From source, with Bun

git clone https://github.com/DennisLoska/losql.git
cd losql
bun install && bun run build
mkdir -p ~/.local/bin
install -m 755 ./losql ~/.local/bin/losql

Requires Bun to build. Add ~/.local/bin to your PATH, or launch ./losql demo directly after building. The compiled binary runs on its own.

02 / Launch

Choose your Connection

losql demo
losql ./app.db
losql postgres://user@localhost/mydb

No database server needed for the demo or SQLite. For the Agent, install and log in to a supported coding CLI separately.
